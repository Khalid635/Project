# Project 1 — Personal Portfolio (HTML + Bootstrap)

An early personal portfolio website for Khalid Bin Masud, built with plain HTML, CSS and Bootstrap 5.

## What's inside

- Sticky navbar (Home, Portfolio, Skills, About, Contact)
- Hero — "I'M KHALID BIN MASUD", Web Developer / React Developer / Programmer
- Portfolio, skills and education sections
- Contact section

## Tech stack

HTML, CSS, Bootstrap 5, JavaScript

## Run it locally

Open `Project 1/index.html` in a browser, or serve it over HTTP:

```bash
cd "Project 1"
python -m http.server 8000
# then open http://localhost:8000
```
